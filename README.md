# BaseMath · 应用数学自学站

高等数学、线性代数、概率论——不是三门课，是描述同一个世界的三种语言：**空间、变化、不确定**。

这个仓库是为一个具体的自学者写的：应用向（工程 / 机器学习）、基础基本忘光、每天不到一小时、不想要教材那套顺序。目标是 **20 周后能用 numpy 从零写出线性回归，并用三种语言解释它为什么有效**。

## 打开

- 本地：双击 `index.html` 即可，无需服务器。
- 在线：在仓库 Settings → Pages 里选 `main` 分支根目录，之后访问 `https://medivhcrf.github.io/BaseMath/`。

## 五条方法

1. **意义先行** —— 先讲它在现实里是什么，再给图，最后才给公式。
2. **三遍法** —— 直觉（当天）→ 工具（第 2 天）→ 应用（第 4 天）。
3. **主动回忆 + 间隔** —— 合上笔记先写再对照；间隔 1 / 3 / 7 / 21 天。
4. **计算 2 : 8** —— 手算只练到能估量级，其余交给 numpy。
5. **交错 + 错因档案** —— 每周混排三科；错题只记一条错因类型。

## 用 skill 继续学

`SKILL.md` 是一份可直接加载的 skill。装到本地：

```bash
mkdir -p ~/.dsh/skills/math-learning
cp SKILL.md ~/.dsh/skills/math-learning/SKILL.md
```

之后在任何对话里说「学数学」「继续下一课」「出题考我」，助手就会按同一套方法教，并接着 `notes.md` 里的进度往下走。
