最小二乘与投影：无解时最好的答案

第 3 课说清了「什么时候无解」。这一课回答更常见的那个问题——无解了，然后呢。

学完你能：把「拟合一条直线」读成「把 b 投影到平面上」；手算 w = (a·b)/(a·a) 和正规方程 AᵀA x = Aᵀb；说出残差为什么垂直于每一列；用 np.linalg.lstsq 三行拟合出一组点；判断 R² 好到什么程度。
这一课的路怎么走：七级台阶（每一级只解决一件事）
  1. 撞墙：四个方程、两个未知数，先老老实实解一次，发现第三式对不上——确认「精确解不存在」。
  2. 换问题：不问「解是什么」，改问「哪组参数让 SSE 最小」；顺带说清为什么用平方而不是绝对值。
  3. 退到最简单的情形：只留斜率、强迫过原点，于是「拟合」变成「把 b 投到 a 这条线上」——2 维，看得见。
  4. 求那个 w：用「残差垂直于 a」写出 w = (a·b)/(a·a)；再用「二次函数求导」得到同一个答案。
  5. 升到 4 维：四点拟合 = 把 y 投到「两列张成的平面」上；「垂直于平面」= 两列都要垂直 = 2 个方程。
  6. 写成矩阵：AᵀA x = Aᵀb；逐个手算 XᵀX、Xᵀy，解一个 2×2。
  7. 验算并读结果：残差和为 0、SSE = 1.80、R² = 0.64——这套东西能干什么、不能干什么。
任何一级卡住，就退回上一级；每节开头都有一句「这一步在干什么」。

1真实问题：四个点，一条过不去的直线

四个学生，学习时长分别是 1、2、3、4 小时，考了 2、3、5、4 分。你想总结一个规律：多学一小时，多考几分。

那就画一条直线 y = w₀ + w₁x，意思是「分数 = 底分 + 每小时涨几分 × 时长」。四个点各给一个要求：

学生时长 x要求它满足实际分数 y
11w₀ + w₁·12
22w₀ + w₁·23
33w₀ + w₁·35
44w₀ + w₁·44

四个方程、两个未知数。先解前两个：w₀ + w₁ = 2、w₀ + 2w₁ = 3 → w₁ = 1、w₀ = 1。代到第三个：1 + 3 = 4，可他是 5 分。差 1 分。

换成 w₀ = 1.5、w₁ = 0.8 试试：四个预测是 2.3、3.1、3.9、4.7，误差 −0.3、−0.1、+1.1、−0.7。每个点都差一点，但每个都不太离谱。

现实里绝大多数问题都是这个形状：方程比未知数多，要求互相打架，精确解根本不存在。这时候的正确问题不是「解是什么」，而是「哪组参数让所有误差合起来最小」。
超定方程组方程个数多于未知数个数（比如 4 个方程、2 个未知数），一般没有精确解。 什么时候遇到：拟合、回归、任何「数据点比模型参数多」的场合——这才是日常，不是例外。 别和「欠定」搞混：欠定是方程比未知数少
（信息不够、无穷多解，第 3 课的零空间），超定是信息太多、互相矛盾。

把四个方程写成一个矩阵式子，形状就露出来了：

X·w = y　　X 是 4×2，w 是 2 个数，y 是 4 个数

4 行 2 列——X 的列空间最多只有 2 维，而 y 住在 4 维空间里。y 要正好落在那个 2 维的「薄片」上才有精确解，概率基本是 0。所以下一步不是硬解，而是把 y 压到那个薄片上，取离它最近的点。

先补一道台阶：「合起来最小」必须先变成一个能算的数

要谈「最小」，得先给每个点量一个误差，再把这些误差压成一个数。第一步没有争议：误差 = 预测 − 实际。第二步有四种常见做法，只有第三种走得通：

把四个误差合成一个数w = (1.5, 0.8) 时是多少能不能用
直接相加−0.3 − 0.1 + 1.1 − 0.7 = 0不行：一条离谱的线也能凑出 0，正负互相抵消
绝对值相加0.3 + 0.1 + 1.1 + 0.7 = 2.2能算，但最小值卡在「拐角」上，写不出公式，只能一个个试
平方相加0.09 + 0.01 + 1.21 + 0.49 = 1.80可以：光滑、唯一、并且能化成线性方程
只看最大误差1.1那是另一类问题（最坏情况拟合），不是这一课

于是把目标换成一个函数：

残差平方和 SSE每个点的误差先平方，再加起来：SSE = Σ (预测ᵢ − 实际ᵢ)² = Σ rᵢ²。最小二乘就是「在所有参数里挑让 SSE 最小的那一组」。 为什么偏爱平方：① 平方把大误差罚得更重（差 1 分罚 1，差 2 分罚 4），符合「偶尔差一点可以，别错得离谱」；② 平方是可导的，求最小值能直接「让导数等于 0」，得到一个线性方程，不用试；③ 如果误差是许多小随机因素相加的结果，平方和最小的解恰好也是概率上最可能的解——这一条现在不懂不要紧，第 8 周概率课会再遇到。 平方和不是唯一合理的标准，只是最好算的标准。数据里若有离谱的离群点，平方会把它放大 4 倍、9 倍，能把整条线拉歪——那时才该换成绝对值或别的准则。
到这一步，问题才算问清楚：不是「解方程」，而是「求一个二元函数 SSE(w₀, w₁) 的最小值」。
剩下的事全是几何：那个最小值点，恰好是 y 在某个平面上的影子。

这件事有个名字：投影。先在 2 维里把它看清楚——把 b 投到一条直线上。

2投影：为什么是「影子」而不是「随便挑个近的」

为什么先退回到「一条线」：它其实是同一道题的简化版

四点拟合发生在 4 维空间里，肉眼看不见。但它有个看得见的简化版：只留斜率、不要底分，也就是强迫直线过原点 y = w₁x。这时模型只剩一列 a = (1, 2, 3, 4)，未知数只剩一个 w₁——而「让 SSE 最小」在几何上就是把 b = (2, 3, 5, 4) 投到 a 这条线上。

用第 1 课的内积直接算：a·b = 1·2 + 2·3 + 3·5 + 4·4 = 39，a·a = 1+4+9+16 = 30，所以 w₁ = 39/30 = 1.3。这条线是 y = 1.3x，预测 1.3、2.6、3.9、5.2，残差 0.7、0.4、1.1、−1.2，SSE = 0.49+0.16+1.21+1.44 = 3.30。

它比「1 + 1x」的 2.00 差，因为被迫过原点；但在所有过原点的直线里，它已经是最好的那条。等把底分 w₀ 也放开（多一列「全 1」），就得到 1.5 + 0.8x、SSE 1.80。所以真正的拟合不是新东西，是同一件事多一列。

拖 bx、by 移动蓝箭头，橙色影子会跟着走。注意橙色和蓝色之间那条虚线始终垂直于绿线——这不是巧合，是投影的定义。

先把「投影」这个词钉死：

投影把一个向量 b 压到某条方向 a 上，得到沿该方向离 b 最近的那个点。记作 proj = ((a·b)/(a·a))·a。 为什么这就是「最近」：所有落在这条线上的点里，只有它到 b 的连线与线垂直；垂线段最短，这是平面几何里就学过的事。 注意投影的结果是一个向量（影子），不是一个数。那个数 w = (a·b)/(a·a) 是「要几个 a 才能凑出影子」。
残差b 减去它的投影：r = b − proj。它就是「模型解释不了的那部分」，也叫误差。（第 3 课那个 0.4472 就是这个东西的长度。） 残差是这一课的主角：最小二乘的全部思想，就是让残差的长度最小。
正交（垂直）两个向量的内积等于 0，就叫正交：a·b = 0。 为什么用内积定义而不是「看着像 90°」：内积对任意维数都成立，100 维里你没法「看」。第 1 课算过，cos 90° = 0，内积正比于 cos。
范数（长度）向量自己的长度，记 ‖v‖ = √(v·v) = √(v₁² + v₂² + …)。 就是勾股定理在任意维数的推广。代码里是 np.linalg.norm(v)。上一课写的 |r| 就是 ‖r‖。

w 是怎么算出来的：一条要求，解一个数

要求只有一条：残差必须垂直于 a。写成式子，再解：

(b − w·a) · a = 0　⟹　a·b − w(a·a) = 0　⟹　w = (a·b)/(a·a)

这就是「为什么是除法」的全部原因，没有别的魔法。拿图上的默认值验证：a = (1, 2)、b = (3, 1)：

量怎么算结果
a·b1×3 + 2×15
a·a1×1 + 2×25

r(3, 1) − (1, 2)(2, −1)
验证r·a = 2×1 + (−1)×20 ✓
‖r‖√(4 + 1)2.236

顺带看一眼：w = 1 意味着影子正好等于 a 本身，不是因为巧合，而是因为 b = (3,1) 在 a 方向上「正好够一个 a」——b − a = (2,−1) 垂直于 a。

不用几何、纯代数也得到同一个 w（这一步是推广的关键）

「垂直」那条路靠看图。把同一个问题写成函数求最小值，会得到一模一样的答案——而且这条路画不出图也能走，这正是它能推广到 4 维、100 维的原因。

SSE(w) = ‖b − w·a‖² = ‖b‖² − 2w(a·b) + w²‖a‖²

右边是 w 的二次式，二次项系数 ‖a‖² 是正的，所以是开口向上的抛物线，一定有一个最低点，位置就在导数等于 0 的地方：

d(SSE)/dw = −2(a·b) + 2w‖a‖² = 0　⟹　w = (a·b)/(a·a)

和上一条「垂直」的式子完全一样。把顶点代回去，还能算出最小 SSE —— 它正好等于残差长度的平方：

SSE_min = ‖b‖² − (a·b)²/(a·a) = 10 − 25/5 = 5 = ‖r‖² = 2.236² ✓

两条路都试一遍的意义：几何那条给你「为什么是影子」，代数那条给你「怎么算，以及为什么一定有唯一答案」。后面多列的情形，靠的就是这个二次函数——只不过那时候变量从一个变成一组。

3从一条线推广到多列：最小二乘

一条直线不够用。拟合直线时，你的模型是「1 和 x 两列的混合」，也是两列——一个负责底分，一个负责斜率。所以真正的投影，是投到两列张成的整个平面上，而不是一条线。

四维里到底发生了什么（这是全课跨度最大的一步）

把两种情形并排看，差异全在「住在几维」和「能落在哪」：

一维情形（§2）四点拟合（§4）
已知向量住几维2 维平面4 维空间（每个学生给一个坐标）
能落在哪一条直线（a 的方向）一个平面（两列张成的）
谁张成它a 一个向量两列：(1,1,1,1) 与 (1,2,3,4)
垂直的要求垂直于 a（1 个方程）两列都要垂直（2 个方程）
解出几个数1 个：w2 个：(w₀, w₁)

关键在第 3、4 行。X·w 的意思是「w₀ 份第一列 + w₁ 份第二列」，所以它永远落在两列张成的那个平面里；而 y = (2,3,5,4) 一般不在这个平面上（在的话就有精确解了）。我们要的，是平面上离 y 最近的那个点。

「最近」的判据还是同一条：连线要垂直于整个平面。而一个向量垂直于一个平面，等价于它垂直于平面里所有方向——只要垂直于张成这个平面的两个基向量就够了。于是 1 个方程变成 2 个：

垂直于第一列：(1,1,1,1)·r = r₁+r₂+r₃+r₄ = 0
垂直于第二列：(1,2,3,4)·r = 1r₁+2r₂+3r₃+4r₄ = 0

两个方程两个未知数，恰好能解。这就是「多一列为什么就多一个方程」——不是硬加的规则，而是「垂直于平面」这句话的直接翻译。

做法一模一样，只是把「垂直于 a」换成「垂直于每一列」：

Aᵀ·r = 0　⟹　Aᵀ(b − Ax) = 0　⟹　AᵀA·x = Aᵀb

这一个式子有个专门名字：正规方程。它把「解不出来的 4 个方程」换成「能解的 2 个方程」。

转置 Aᵀ把矩阵的行列对调：原本第 i 行第 j 列的数，搬到第 j 行第 i 列。4×2 的 A 转置后是 2×4。 它为什么出现在这里：A 把 2 维的 w 送到 4 维，而我们要在 4 维里做内积检查——Aᵀ 负责把 4 维的残差「收」回 2 维，于是「垂直于每一列」就变成一个 2×4 乘 4×1 的式子。 工程上别手写转置再相乘，用 A.T @ A，numpy 会处理。
最小二乘在无精确解时，取让残差长度的平方最小的那个 x。因为平方，记号叫 least squares。 为什么是平方而不是绝对值：平方可导，能写成正规方程（线性方程）；绝对值的最优点会卡在点上，没有公式。而且平方对大误差惩罚更重——这符合「别错得太离谱」的直觉。 它不是「随便一个近解」，而是唯一的最优点（当 A 的列线性无关时）。
正规方程AᵀA·x = Aᵀb。左边方阵、右边已知，直接 solve 就行。 它的几何含义：残差与 A 的每一列都正交——投影的定义式，只是写成矩阵。 AᵀA 一定对称，但不一定可逆。列有重复（比如两列测的是同一件事，第 3 课的亏秩）时它就奇异，这时要用伪逆 / SVD，numpy 的 lstsq 已经替你处理。
一句话串起来：无解 → 找最近的 → 最近的点就是投影 → 投影的判据是残差正交 → 正交写成矩阵就是正规方程。
四步，一环扣一环，没有跳步。

4回到四个点：拟合一条直线

现在把四个点真的拟合一遍。模型是 y = w₀ + w₁x，写成矩阵：

X = [[1, 1], [1, 2], [1, 3], [1, 4]]　　y = (2, 3, 5, 4)

第一列全是 1，因为 w₀ 对每个点都加一次；第二列是时长。

切到图上的「四个点拟合直线」模式，拖两个滑块，看 SSE（残差平方和）怎么变：

1.8 是最小的那个。它怎么来的？解正规方程：

XᵀX = [[4, 10], [10, 30]]　　Xᵀy = (14, 39)　　⟹　w = (1.5, 0.8)

XᵀX 和 Xᵀy 里的每个数是怎么来的

这两个结果看着像凭空冒出来的，其实只有一条规则：XᵀX 的第 i 行第 j 列，就是 X 的第 i 列与第 j 列的内积（4 维向量的内积，第 1 课那个「逐项相乘再相加」）；Xᵀy 的第 i 个分量，是第 i 列与 y 的内积。

所以左上角的 4 就是「有几个数据点」，右上角的 10 是「时长总和」1+2+3+4，右下角的 30 是「时长平方和」1+4+9+16。统计书上写 n、Σx、Σx²、Σy、Σxy——同一批数，换了个名字而已。这也是为什么正规方程看起来和统计课的最小二乘公式是同一个东西。

解的过程：4w₀ + 10w₁ = 14、10w₀ + 30w₁ = 39 → 第一式乘 2.5 得 10w₀ + 25w₁ = 35，减去第二式：5w₁ = 4 → w₁ = 0.8，代回 w₀ = 1.5。答案和图上「跳到最优」按钮一模一样。

再验一下残差是不是真的垂直于两列：X 的两列是 (1,1,1,1) 和 (1,2,3,4)。

和谁做内积计算结果
第一列（全 1）−0.3 − 0.1 + 1.1 − 0.70 ✓ 残差和为 0
第二列（时长）−0.3 − 0.2 + 3.3 − 2.80 ✓

第一列内积为 0 有个好记的说法：最小二乘的残差，加起来一定等于 0。以后看到残差和不为 0，说明哪里算错了。

这个 1.8 算好还是算差？

决定系数 R²用模型解释掉的波动比例：R² = 1 − SSE / SST，其中 SST 是 y 自己的平方波动（都拿平均值当预测时的 SSE）。 它的读法：R² = 0.64 表示「分数的波动里，64% 能被学习时长解释」，剩下 36% 是别的因素。0 到 1 之间，越接近 1 拟合越紧。 别把它当真理：R² 高不等于模型对（可能过拟合，也可能只是变量在同步变化），R² 低也不等于没用。它衡量的是「解释了多少波动」，不是「因果」。另外只有带截距的模型才有这个定义。

这道题的 SST = (2−3.5)² + (3−3.5)² + (5−3.5)² + (4−3.5)² = 2.25 + 0.25 + 2.25 + 0.25 = 5.0，所以：

R² = 1 − 1.8 / 5.0 = 0.64

四个点的散落程度，用一条直线解释掉了 64%。这不是「对」或「错」，是「够不够用」——做预测够用，做因果结论远远不够。

为什么正式代码里推荐 lstsq 而不是自己解正规方程：AᵀA 会把条件数平方（第 3 课那个 40002，平方之后就是 1.6×10⁹），浮点误差被放大得厉害。lstsq 背后是 QR 分解，绕开了这一步。

6动手：10 分钟，用 numpy 验证

# 1. 一维投影：把 b 投到 a 上
import numpy as np
a = np.array([1, 2]); b = np.array([3, 1])
w = (a @ b) / (a @ a)              # 1.0
proj = w * a                       # [1. 2.]
r = b - proj                       # [ 2. -1.]
print(w, proj, r @ a, np.linalg.norm(r))   # 1.0  [1. 2.]  0.0  2.2361

# 2. 四个点拟合直线
x = np.array([1, 2, 3, 4], dtype=float)
y = np.array([2, 3, 5, 4], dtype=float)
X = np.column_stack([np.ones_like(x), x])     # 第一列全是 1：截距项
w, sse, rank, sv = np.linalg.lstsq(X, y, rcond=None)
print(w)                          # [1.5 0.8]
print(sse)                        # [1.8]

# 3. 残差是否垂直于每一列
r = y - X @ w
print(X.T @ r)                    # [~0. ~0.]

# 4. 正规方程自己解一遍，和 lstsq 对照
print(np.linalg.solve(X.T @ X, X.T @ y))   # [1.5 0.8]

# 5. 一个「列重复」的坏例子：第三列等于第一列
X2 = np.column_stack([X, np.ones_like(x) * 1.0])
print(np.linalg.matrix_rank(X2))  # 2 —— 列不满秩
print(np.linalg.lstsq(X2, y, rcond=None)[0])  # 仍然给一个解（最小范数）

跑完做三件事（比读代码重要）：

① 把第 1 段里的 b 改成 (2, 4)，看 w 变成 2、残差变成 0——b 正好落在方向上时，投影就是 b 自己。
② 把第 3 段打印的 X.T @ r 抄下来，它不是精确的 0（约 1e-16），这是浮点误差，量级这么小就该读成 0。
③ 把第 5 段的 rank 打印出来，再去掉第三列，rank 变回 2——重复的列不带来新信息，这就是「秩」在拟合里的样子。

7练习：六道，做完对答案

1、4 手算；2、5 推导；3、6 用 numpy。卡住先看提示。

1a = (1, 3)、b = (4, 2)。求 b 在 a 上的投影、残差、残差长度，并验证残差与 a 正交。
先算 a·b 和 a·a，再用 w = 商。
对答案
a·b = 4 + 6 = 10，a·a = 1 + 9 = 10，w = 1。 proj = (1, 3) r = (4, 2) − (1, 3) = (3, −1) ‖r‖ = √10 ≈ 3.1623 r·a = 3 − 3 = 0 ✓ 正交。 顺带一句：w = 1 说明影子正好是 a 本身。
2三个点 (0, 1)、(1, 3)、(2, 4)，拟合直线 y = w₀ + w₁x。求 w、残差、SSE。
X 是 3 行 2 列：[[1,0], [1,1], [1,2]]。先算 XᵀX 和 Xᵀy。
对答案
XᵀX = [[3, 3], [3, 5]]，Xᵀy = (8, 11)。 解：3w₀ + 3w₁ = 8、3w₀ + 5w₁ = 11 → 2w₁ = 3 → w₁ = 1.5，w₀ = 8/3 − 1.5 ≈ 1.1667。 预测：(1.1667, 2.6667, 4.1667)，残差：(−0.1667, 0.3333, −0.1667)。 SSE = 0.0278 + 0.1111 + 0.0278 = 0.1667（精确值是 1/6）。 验算：残差和 = 0 ✓；残差与 x 的内积 = 0 + 0.3333 − 0.3333 = 0 ✓。
3AᵀA 什么时候不可逆？给出一个具体例子，并说明 lstsq 在这种情况下怎么处理。
想想第 3 课的亏秩：什么样的列会让「垂直于每一列」这个条件失去唯一性？
对答案
当 A 的列线性相关（有一列能由别的列凑出来）时，AᵀA 奇异，不可逆。 例子：A = [[1, 1], [1, 1]]，两列完全一样，AᵀA = [[2, 2], [2, 2]]，det = 0。 几何原因：列空间塌成一条线，投影点唯一，但「凑出投影的系数」有无穷多组——沿零空间移动不改变 Ax。 lstsq 的处理：返回长度最小的那组系数（最小范数解），即把解沿零空间平移到离原点最近。这就是第 3 课「lstsq 总给一个解」的确切含义。
4a = (1, 1)、b = (4, 2)。求 b 在 a 上的投影、残差、残差长度，并验证正交。再解释 w = 3 的含义。
a·a 很小（只有 2），所以 w 会比上一题大。
对答案
a·b = 4 + 2 = 6，a·a = 1 + 1 = 2，w = 3。 proj = 3 × (1, 1) = (3, 3)；r = (4, 2) − (3, 3) = (1, −1)；‖r‖ = √2 ≈ 1.4142。 r·a = 1 − 1 = 0 ✓ 正交。 w = 3 的意思是「影子里装了 3 个 a」。同一道题里 w 会变，因为 a 的长度变了——这就是为什么公式要除以 a·a，而不是直接除以 a·b。
5三点 (1, 2)、(2, 3)、(3, 5)。先强迫过原点 y = w₁x 求最优 w₁ 与 SSE；再放开截距求 (w₀, w₁) 与 SSE。哪个好？好多少？
过原点时模型只有一列 x，w₁ = (x·y)/(x·x)。放开截距就是加一列全 1。
对答案
过原点：x·y = 2 + 6 + 15 = 23，x·x = 1 + 4 + 9 = 14，w₁ = 23/14 ≈ 1.6429，SSE = 3/14 ≈ 0.2143。 带截距：XᵀX = [[3, 6], [6, 14]]、Xᵀy = (10, 23) → w = (1/3, 1.5) ≈ (0.3333, 1.5)，SSE = 1/6 ≈ 0.1667。 带截距更好，而且不可能更差：过原点的模型是它 w₀ = 0 的特例，多一个参数只会让最小值更低或持平。 但参数不是白给的：多一个参数就多一份「解释成本」，也更容易过拟合。判断用哪个，看「少掉的这点误差值不值得」——差 0.048，对三个点意义有限。
6（编程）同一组三点，分别用 lstsq、polyfit、正规方程求直线，对比结果与 SSE，再算 R²。为什么工具表推荐 lstsq？
import numpy as np
x = np.array([1., 2, 3]); y = np.array([2., 3, 5])
X = np.column_stack([np.ones(3), x])
w1 = np.linalg.lstsq(X, y, rcond=None)[0]
w2 = np.polyfit(x, y, 1)[::-1]            # polyfit 返回 [斜率, 截距]
w3 = np.linalg.solve(X.T @ X, X.T @ y)
for w in (w1, w2, w3):
    print(w, np.sum((y - X @ w) ** 2))
print(1 - np.sum((y - X @ w1)**2) / np.sum((y - y.mean())**2))
三个答案应该一样；注意最后的 R² 落在什么区间。
对答案
三种方法都给 (0.3333, 1.5)，SSE = 1/6 ≈ 0.1667，R² = 1 − 0.1667/4.6667 = 0.9643。 它们是同一件事的三种包装：polyfit 内部也是最小二乘；solve(正规方程) 是最教科书、数值最不稳的做法。 为什么推荐 lstsq：显式构造 XᵀX 会让条件数平方。这组数据 cond(X) ≈ 6.79，而 cond(XᵀX) ≈ 46.14——数据一病态，正规方程就先垮。 R² = 0.96 的意思是「分数波动的 96% 被直线解释了」，比第 4 节那组四点（0.64）高得多——但那组数据更散，所以低。R² 只能横着比同一批数据上的不同模型，不能跨数据集比。

8收尾：四问自测

合上讲义，先自己答，再展开。
  1. 为什么「无解」在现实里是常态，而不是异常？
  2. 投影为什么必须是「垂直」的那个点？
  3. 正规方程 AᵀA x = Aᵀb 是从哪句话推出来的？
  4. SSE = 1.8、R² = 0.64，这两句话分别说了什么？
对答案
1. 因为方程个数通常多于未知数（超定），而 b 落在低维列空间之外的概率是压倒性的。数据越多越「打架」。 2. 因为垂线段最短——在一条线上找离 b 最近的点，那条连线只能垂直于线。反过来，垂直的那个点也一定是最近的，两个方向都成立。 3. 从「残差垂直于每一列」推出来的：Aᵀr = 0，展开 Aᵀ(b − Ax) = 0，移项即得。它就是投影的定义写成矩阵。 4. SSE 是绝对量：残差平方和，单位是「分²」，只适合和别的模型比。R² 是相对量：模型解释掉 64% 的波动，无量纲，能跨问题比。
