总览 第 1–5 课 一页纸 · 30 分钟

五课一条线：从一条数据到不动的那几条线

第 1–5 课不是五个知识点，是一条链上的五段。每一课收尾都留了一个「明日问题」，而那个问题恰好就是下一课的开头——把它们连起来，就是整个阶段 1。

看完这一页你能：不翻书，用一张纸画出「向量 → 矩阵 → 秩 → 投影 → 特征值」这条链；每课说出一个核心式子；把 12 道混合题答对 10 道以上；知道下一课 PCA 是从哪儿长出来的。

1主线：五个问题接成一条链

这条链的问法是：数据长什么样 → 谁能搬动它 → 能搬到哪 → 搬不到怎么办 → 一直搬下去会停在哪。每一步都不是新话题，是上一步留下的问题。

1
向量 · 一条数据长什么样
一串有序的数。长度说「多强」，方向说「是什么类型」；判「像不像」看方向，不看长度。
a·b = Σaᵢbᵢ cos = a·b / (|a|·|b|)
明日问题 余弦能说「有多像」，但我想把 A 变成 B，该怎么「变」？
→ 第 2 课：矩阵是一次变换
2
矩阵 · 一次把整个空间搬动
矩阵不是数字表，是「把每个点重新派一个位置」的规则；两列就是 e₁、e₂ 的新家。
A·x = x₁·col₁ + x₂·col₂ det = ad − bc
明日问题 det = 0 时，被压没的方向去哪了？「保留几个独立方向」用什么数说？
→ 第 3 课：秩
3
秩 · 什么时候有解
秩 = 真正互相独立的列有几个。Ax = b 只有三种结局；无穷多解写成「特解 + 零空间的任意组合」。
rank = 独立列数 = dim Col(A) x = x_p + t·n
明日问题 b 落不到列空间里时，投影点怎么算？为什么垂着落下去的那条最好？
→ 第 4 课：最小二乘与投影
4
投影 · 无解时最好的答案
无解 → 找最近的 → 最近点就是投影 → 投影的判据是残差垂直于列空间 → 写成矩阵就是正规方程。
proj = (a·b / a·a)·a AᵀA x = Aᵀb R² = 1 − SSE/SST
明日问题 要投影到「最能代表数据的方向」，这个方向怎么找？提示：它跟「乘完方向不变」有关。
→ 第 5 课：特征值与特征向量
5
特征值 · 变换里不动的那几条线
矩阵会拧几乎所有方向，只有几条线它不敢动、只敢改长度；那个倍数 λ 决定反复作用后谁胜出。
A v = λ v det(A − λI) = 0 Aᵏv = λᵏv
下一站 把「最值钱的方向」用在数据上：协方差矩阵的特征向量 = 主成分。
→ 第 6 课：PCA
一句话缝起来：数据是向量 → 矩阵是搬它的规则 → 秩说它能被搬到哪 → 搬不到时，投影给出最近的答案 → 反复搬下去，方向会停在特征向量上。

3每课带走三样

一张卡片 = 一句核心 + 必须会的式子 + 最容易错的那一点。三样都答得出来，这一课就算过了。

第 1 课 · 向量与内积 重读

内积只回答「对上了多少」，不回答「像不像」；要问像不像，先把两个长度除掉。

必须会：

  • |a| = √Σaᵢ² —— 这支箭有多长
  • a·b = Σaᵢbᵢ —— 逐项相乘再相加，结果是一个数
  • cos = a·b / (|a|·|b|) ∈ [−1, 1] —— 只看方向，看不见长度
  • a·b = 0 ⟺ 正交 —— 毫无方向关系（二维里就是垂直）

最容易错：内积大 ≠ 像，长度会把它放大；余弦 0.5 不是「50% 像」，是夹角 60°；它不是百分比。

第 2 课 · 矩阵是一次变换 重读

矩阵不是一张数字表，是一台「把每个点重新派一个位置」的机器；两列就是基向量被搬到了哪。

必须会：

  • A·e₁ = 第一列，A·e₂ = 第二列 —— 竖着看列
  • A·x = x₁·col₁ + x₂·col₂ —— 用 x 的两个数去混合两列
  • det = ad − bc = 面积倍数 —— 负号表示翻面，0 表示压扁
  • 可逆 ⟺ det ≠ 0 ⟺ 两列不共线

最容易错：横着把 a、b 当一组读（要竖着读列）；det 只对方阵有定义，2×3 没有行列式。

第 3 课 · 秩与方程组 重读

系统给不出唯一答案只有两种原因：读数互相重复（信息不够），或者互相矛盾（信息打架）。区分它们的是秩。

必须会：

  • rank(A) = 独立列数 = dim Col(A) = 消元后非零行数
  • Col(A) = {A·x} —— b 在不在列空间里，决定有没有解
  • Null(A) = {x : A·x = 0} —— 决定解唯一不唯一
  • x = x_p + t·n —— 通解 = 特解 + 零空间

最容易错：把「矩阵」当「变量」（矩阵是规则，变量是未知数）；病态（cond 大）不是无解，那是数值问题，不是结构问题。

第 4 课 · 最小二乘与投影 重读

无解时正确的问法不是「解是什么」，而是「哪组参数让所有误差合起来最小」。

必须会：

  • proj = (a·b / a·a)·a —— 影子是一个向量，那个系数才是参数
  • r = b − proj ⟂ 每一列 —— 垂直 = 最近点的判据
  • AᵀA·x = Aᵀb —— 正规方程，把几何翻译成矩阵
  • R² = 1 − SSE/SST —— 解释掉了多少波动

最容易错：残差是向量不是数；R² 高不等于模型对（可能只是变量在同步变），更不等于因果；AᵀA 对称，但不一定可逆。

第 5 课 · 特征值与特征向量 重读

矩阵会拧几乎所有方向，但总有几条线它不敢动，只敢改长度——这几条线描述了它「真正的性格」。

必须会：

  • A·v = λ·v（v ≠ 0）—— 方向不变，长度乘 λ
  • det(A − λI) = 0 —— 手算 λ 的入口
  • λ₁ + λ₂ = tr(A)，λ₁·λ₂ = det(A) —— 两条免费检查
  • Aᵏv = λᵏv —— 算 k 次变成乘一个数

最容易错：特征向量不唯一（v 和 5v 是同一个方向，报单位向量）；旋转矩阵一个实特征值都没有；两个特征值绝对值相等时不会收敛。

512 道混合自测

顺序是打乱的（交错练习）。先遮住答案自己写，再点开对；答不上来的那题，回对应课重读那一节。

1两个向量的内积很大，能说明它们「像」吗？
看答案
不能。内积 = |a||b|·cos，长度会把它放大：两支很长的箭，哪怕夹角不小，内积也可以很大。 判「像不像」要先除掉长度：cos = a·b/(|a|·|b|)。这就是第 1 课的分工——长度管「程度」，方向管「类型」。
2A = [[2, 1], [1, 2]]。它把 (1, 0)、(0, 1) 分别送到哪？那 (3, 4) 呢？
看答案
(1,0) → (2,1)，(0,1) → (1,2)——正好是矩阵的两列。 A·(3,4) = 3×(2,1) + 4×(1,2) = (6,3) + (4,8) = (10, 11)。用「列的混合」算比逐行乘更快，也不容易错。
3秩的三种等价说法是什么？
看答案
① 矩阵里真正互相独立的列有几个；② 列空间 Col(A) 的维数；③ 消元之后非零行的个数。 三种说法说的是同一个数。第③条是手算时最好用的。
4为什么最小二乘的残差必须垂直于列空间？
看答案
因为「垂直」就是「已经不能再近」的判据：如果残差在某个列方向上有分量，沿那个方向挪一点就能让 |r| 更小，那它就不是最近点。 写成式子：Aᵀr = 0 → Aᵀ(b − Ax) = 0 → AᵀA x = Aᵀb。几何一句话，代数就是正规方程。
5为什么 Aᵏv = λᵏv？
看答案
因为 Av = λv。再乘一次 A：A²v = A(λv) = λ(Av) = λ²v；一路归纳下去就是 Aᵏv = λᵏv。 这一步是第 5 课全部用处的来源：把「算 k 次」变成「乘一个数」，于是 3ᵏ 那一项会压倒其它项。
6余弦相似度等于 0.5，是什么意思？
看答案
两支箭的夹角是 60°。 它不是「50% 像」——余弦不是百分比，取值范围是 −1 到 1，0 才是「毫无方向关系」（正交）。
7det = 0 在几何上意味着什么？
看答案
面积（三维里是体积）的放大倍数归零：整个平面被压成一条线或一个点。 后果：不同的点被挤到一起，信息丢了，矩阵不可逆——没有逆矩阵能把结果还原回去。
8一个 4×2 的矩阵，秩可能是几？
看答案
0、1 或 2。 只有两列，所以最多 2；两列共线时是 1；全零矩阵是 0。行数再多也顶不上去——秩被「较小的那个维数」卡住。
9正规方程长什么样？它一定可解吗？
看答案
AᵀA·x = Aᵀb。 AᵀA 一定对称，但不一定可逆：列线性相关（亏秩）时它就奇异。这时要用 lstsq / 伪逆，不能直接 solve。
10一个 2×2 的旋转矩阵为什么没有实特征值？
看答案
它把每个方向都转走了，没有任何方向保持不变——而特征向量的定义就是「方向不变」。 代数上看判别式：tr = 2cosθ、det = 1，tr² − 4det = 4cos²θ − 4 = −4sin²θ < 0（θ 不是 0 或 180°），没有实根。
11det = 0 和特征值有什么关系？
看答案
det = λ₁·λ₂，所以 det = 0 ⟺ 至少有一个 λ = 0 ⟺ 存在被压成零的方向 ⟺ 不可逆。 第 2 课的行列式、第 3 课的秩与零空间、第 5 课的特征值，说的是同一件事的三种语言。
12「病态」（cond 很大）和「无解」有什么区别？
看答案
病态是数值问题：秩满、有唯一解，但输入里很小的误差会被放大（cond = 100 时 0.1% 变成 10%）。 无解是结构问题：b 根本不在列空间里，秩不够。前者换算法（换基、正则化）能缓解，后者只能退而求最小二乘。

第 6 课：PCA——把 12 个数压成 6 个数

五课在这里合流：数据是向量，协方差是矩阵，它的特征向量就是「最值钱的方向」，特征值是那个方向上的方差；把数据投影到前几个方向上，就完成了降维。前面每个词，你都已经学过了。
