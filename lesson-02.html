矩阵：一次把整个空间搬动的规则

这一课只解决一件事——「线性变换」到底在干什么。它是旋转、缩放、投影、PCA 的共同语法。

学完你能：把一个矩阵读成「基向量的新位置」；用列的线性组合算 A·x；用行列式判断它把面积放大几倍、有没有把平面压扁；用 numpy 画出一张网格被变换后的样子。

1先从一个真实问题开始

你在修图软件里点一下「旋转 90°」，整张照片转过去了。软件并没有搬动任何一个像素——它把每个像素的坐标 (x, y) 按同一个规则换成 (-y, x)。

验算一下：右上角 (100, 0) 转完去哪？(0, 100)。左上角 (0, 0) 不动。把这条规则写成两行：

x′ = 0·x − 1·y　　y′ = 1·x + 0·y

这四行数字排成方阵，就是矩阵：

A = [ 0−110 ]

所以先说结论：矩阵不是一张数字表，是一台把整个空间按固定规则搬动的机器。你喂它一个点，它吐出一个新点；而且同一个规则同时作用于所有点——这就是「线性」的意思：原点不动，网格线变换后仍然是直线。

矩阵 A（m 行 × n 列） 一个排成矩形的数阵，写作 A = [[a, b], [c, d]]。它有三种身份，本课主要用第二种：一张数据表 / 一个线性变换的坐标写法 / n 个列向量并排捆在一起。 为什么要写成数阵：这样「规则」才能被乘。「先搬一次、再搬一次」于是变成两个矩阵相乘，整条链子就能用一个矩阵表示。
线性变换 T 一个函数 T: ℝⁿ → ℝᵐ，满足两条：T(u+v) = T(u)+T(v)、T(ku) = k·T(u)。等价的一条直觉：原点不动，直线还是直线，等距的点还等距。 这两条合起来的意思是「不弯、不平移」。所以旋转、缩放、剪切、投影都是线性的；而「把图片往右挪 10 像素」不是（那叫仿射，要额外加一个平移向量）。
为什么这件事值得学：你以后会遇到的「图像旋转」「数据标准化」「把 784 维压成 2 维」「神经网络的一层」，全都是这一台机器。

下面这张图里有两个世界：灰色网格是原来的空间，彩色网格是被矩阵搬动之后的空间。四个滑块就是矩阵的四个数——拖动它们，看整张网格怎么被拉扯。

a1.00
b0.00
c0.00
d1.00
浅色虚线是原来的单位正方形，实线是它变换后的样子；红箭头 = (1,0) 被搬到的位置，蓝箭头 = (0,1) 被搬到的位置。

读这张图，只要盯住三件事：

① 单位正方形变成了平行四边形。线性变换可以把正方形拉长、压扁、转、翻面，但永远不会把它变成弯的东西——因为它只能「均匀地」作用，不许有弯曲。

② 红蓝两支箭头就是矩阵的两列。红箭头指向 (a, c)，蓝箭头指向 (b, d)。这不是巧合，下一节讲。

③ det 那个数字在变。它告诉你面积被放大了几倍；拖到「压成一条线」，det 变 0，整个平面塌了。

四个滑块，各管一件事

滑块是 a, b, c, d，对应矩阵 [[a, b], [c, d]]。但竖着看才是一列：(a, c) 是红箭头，(b, d) 是蓝箭头。这是这张图最容易读反的地方——横着相邻的 a 和 b，其实属于两支不同的箭头。

滑块它改的是拖它，你会看到
a第一列的上分量红箭头左右摆 → 所有点 x 坐标乘 |a|，格网被横向拉开／压扁（竖线仍是竖线）
c第一列的下分量红箭头上下歪 → 横线被推斜（剪切），竖线仍是竖线
b第二列的上分量蓝箭头左右歪 → 竖线被推斜（剪切），横线仍是横线
d第二列的下分量蓝箭头上下摆 → 所有点 y 坐标乘 |d|，格网被纵向拉开／压扁（横线仍是横线）

三分钟上手顺序（照这个次序拖，比乱拖有效）：① 先把 a 推到 2，看横向拉伸，再推回 1；② 把 d 推到 0.5，看纵向压缩；③ 把 b 推到 1（矩阵变 [[1,1],[0,1]]），此时只有蓝箭头歪了，所有竖线倾斜成「斜体字」——这就是剪切；④ 按「压成一条线」，看格子塌成一条；⑤ 按「左右镜像」，注意 det 变成负数，格子的手性翻了。

顺便验一下上一个问题的答案：你拖遍所有滑块，彩色格网始终画在同一个平面里，一格都没跑到别处去——变的只是每个点的位置，不是空间本身。

为什么 b 和 c 不像「控制左右／上下」

这是四个滑块里真正让人卡住的地方。先把它写成坐标形式，一眼就清楚了：

x′ = a·x + b·y　　　y′ = c·x + d·y

换个读法：矩阵第 i 行第 j 列，就是「输入的第 j 个坐标有多少跑进输出的第 i 个坐标」。于是四个位置自动分成两类：

位置索引关系它在做几何效果
a（第1行第1列）1 对 1，自己对自己x 影响 x′沿 x 轴缩放
d（第2行第2列）2 对 2，自己对自己y 影响 y′沿 y 轴缩放
b（第1行第2列）2 影响 1，串轴y 混进 x′剪切：竖线歪
c（第2行第1列）1 影响 2，串轴x 混进 y′剪切：横线歪

所以 a、d 之所以显得「一个管左右、一个管上下」，是因为它们只在自己那条轴上动手；b、c 是把一条轴的量搬到另一条轴上，天生就不可能是「控制上下」或「控制左右」这么简单的事。

拿 b 具体算三下（此时 A = [[1, b],[0, 1]]，a=1、c=0、d=1）：

b输入输出读法
0.5(1, 0)(1, 0)躺在 x 轴上的点不动——没有高度可供搬
0.5(1, 2)(2, 2)往右挪了 0.5×2 = 1，挪的量正比于高度
0.5(2, 1)(2.5, 1)高度 1，只挪 0.5

关键在最后一句：挪的量随高度变化。所以整张网格不是「整体右移」，而是越往上推得越远——竖线被掰成斜线。而「整体右移」根本做不到：矩阵必须把原点 (0,0) 钉死不动，平移会把它搬走，那是仿射变换，不是线性变换。

c 完全对称：c = 0.5 时 (1, 2) → (1, 2.5)，越往右推得越高，横线变斜、竖线不动。两个方向一起开就是「双向剪切」，格子像被揉歪的方格纸。

一句话：对角线上那两个数在「缩放」，对角线外那两个数在「搬运」。
缩放有方向（左右／上下），搬运没有——它只负责把一条轴的分量倒进另一条轴。

顺带一个能自己验的性质：纯剪切（a = d = 1，b 或 c 随便）的 det 永远是 1。歪是歪了，面积一点没变——就像把一摞书斜着推倒，书的总体积没变。

升到三维：九个数的「滑块图」

二维那张图，四个滑块 = 两行 × 两列。升到三维，矩阵是 3×3，一共九个数（不是五个），还是三行 × 三列。读法一个字都没变：竖着看列，每一列是一支基向量箭头的新家，只是这支箭头现在有三个分量。

列在矩阵里的位置它回答的问题
第 1 列最左边一竖（上中下三个数）e₁ = (1,0,0) 被搬到哪
第 2 列中间一竖e₂ = (0,1,0) 被搬到哪
第 3 列最右边一竖e₃ = (0,0,1) 被搬到哪

所以「某个数各自控制一个变化量」这个直觉要修一下：一个数控制不了什么，三个数才决定一支箭头去哪；三支箭头全定了，整个空间里每个点的去向就全定了。二维时你说得对，是因为那时一列只有两个数，看起来「数 = 一个方向」；维数一高，主语的粒度变成「列」。

拿 A = [[1, 0.5, 0], [0, 1, 0], [0, 0, 2]] 试（三列分别是 (1,0,0)、(0.5,1,0)、(0,0,2)）：

作用到结果发生了什么
(1,0,0)(1,0,0)没动
(0,1,0)(0.5,1,0)朝 x 方向歪了一点（剪切）
(0,0,1)(0,0,2)z 方向拉长一倍
(2,3,4)(3.5,3,8)三个坐标按列混一遍：2 + 0.5×3 = 3.5，3，4×2 = 8

九个数的分工有个粗略规律（当直觉用，别当定理）：

位置直觉
对角线（左上、正中、右下）管「沿自己那条轴的拉压」——把该方向放大或压扁
非对角线管「把一条轴推歪到另一条轴方向」——剪切。比如左下的 1 把 y 推进 z

读数也升了一级：二维的「面积倍数」在三维变成体积倍数。上面那个 A 的 det = 2，意思是单位立方体变成体积为 2 的平行六面体；绕 z 轴转 30° 的旋转矩阵 det = 1，所以旋转不改体积——这就是为什么「旋转」在二维那张图上滑块在动、面积读数却一直是 ×1.00。det = 0 时体积塌成 0：整个三维空间被压进一张平面（rank 只剩 2），但它仍然是三维空间里的平面，没搬到别处去。

三维别硬想「两套网格」。二维你能同时看见灰格子和彩格子，三维看不全，越想越糊。换成这个想法就够用：盯住三支箭头（就是三列）和它们围出的那个平行六面体。箭头怎么动，空间就怎么变；平行六面体的体积，就是 det。

3矩阵的列，就是基向量的新家

这是这一课唯一需要真正记住的东西。先看一个事实：任何向量都能拆成两个基本方向的组合。

x = (x₁, x₂) = x₁·e₁ + x₂·e₂
线性组合 / 基 / 基向量 手上一组向量 v₁ … v_k 和一组数 c₁ … c_k，c₁v₁ + … + c_kv_k 就叫它们的线性组合——按配方调一杯饮料，系数就是配方比例。
如果平面里每个点都能用这组向量唯一地调出来，这组向量就叫这个平面的一组基，每一个叫基向量。最常用的一组是 e₁ = (1,0)、e₂ = (0,1)。 「选定一组基」= 选定一种语言。坐标系就是这套语言的语法：点本身没动，换个说法而已。而矩阵的每一列，就是「原来的基向量被搬到哪儿去了」。

其中 e₁ = (1, 0)、e₂ = (0, 1)。而线性变换有一个性质：先组合再变换 = 先变换再组合。于是：

A·x = x₁·(A·e₁) + x₂·(A·e₂)

而 A·e₁ 是什么？就是把 (1,0) 代进矩阵，得到的正好是矩阵的第一列；同理 A·e₂ 是第二列。所以：

矩阵乘向量 = 用 x 的两个数，去混合矩阵的两列。
A·x = x₁ × (第一列) + x₂ × (第二列)

拿一个具体矩阵试：

A = [ 2103 ] x = [ 12 ]

用「列的混合」算：

A·x = 1×(2, 0) + 2×(1, 3) = (2, 0) + (2, 6) = (4, 6)

再用课本上的「行乘列」验算：第一行 2×1 + 1×2 = 4，第二行 0×1 + 3×2 = 6。一样。

这条式子顺手解释了两件以前觉得莫名其妙的事：为什么矩阵乘法是「行乘列再相加」——它不是规定，是线性变换的必然结果；为什么 A·x 和 x·A 不是一回事——前者是拿 x 去混合列，后者根本不是一个合法的动作。

变换之后，那个向量住在哪个空间？

很多人卡在这句话上：「矩阵把空间变了，那 A·x 是在新空间里，还是在原来那个空间里？」答案要看矩阵的形状，分两种情况。

矩阵输入输出换空间了吗
2×2 方阵平面上的点平面上的点没换：同一个平面、同一套坐标轴
2×3三维里的一点（3 个数）二维平面上的一点（2 个数）换了：出口是另一个维度的空间（降维）

所以对 2×2 来说，根本不存在一个「新空间」。真正发生的事是：坐标轴原地不动，而每个点被挪到了新位置。你量 A·x 的坐标，用的还是 (1,0)、(0,1) 这把老尺子——变的不是尺子，是被量的东西。

A·(1, 1) = (2, 1)　←　点从 (1,1) 挪到 (2,1)，坐标轴一步没动

那「矩阵是空间的变换」这句话错了吗？没错，只是省略了主语：变的是空间里所有的点，不是空间被搬去了别处。所有点同时按同一条规则移动，看起来才像整个空间被拉长、压扁、转过去。

三个说法，一句话分开：
· 轴不动、点动 → 这是变换（本课的主线，也叫主动视角）
· 轴动了、点没动，只有坐标数字变了 → 这是换基（同一个变换换种描述，叫被动视角）
· 所有点被压到一条线或一个面上 → 这不是搬家，是压扁：输出还住在同一个平面里，只是能落到的位置变少了（秩 < 2，见第 3 课）

「压扁」长什么样？看两列还指不指向两个不同方向。取 A = [[1, 2], [2, 4]]：第一列 (1,2)、第二列 (2,4) 在同一条直线上，整个平面被压进直线 y = 2x。平面上随便挑一点，变换后都落在那条线上。输出仍然住在原来的平面里，只是住得很挤。

把这一节收住：矩阵不负责把东西搬进新空间，它负责给每一个点重新派一个位置；只有当矩阵的行数 ≠ 列数时，出口才是另一个维度的空间。

4行列式：面积被放大了几倍

单位正方形的面积是 1。它被矩阵变换成平行四边形之后，面积变成 |det A|。所以行列式有一个非常物理的读法：

det A = 面积放大倍数（带正负号，负号表示翻了面）
行列式 det A（只对方阵有定义） 2×2 时 det A = ad − bc。它的几何意义是面积（三维里是体积）的放大倍数，正负号负责报告「有没有翻面」。 一张表读到底：|det| > 1 放大、< 1 缩小、= 1 面积不变（旋转、剪切都属这类）、= 0 压扁了（不可逆，信息丢了）、< 0 翻了面（像照镜子）。 det 只对方阵存在。2×3 那样的矩阵没有行列式；想知道它把「体积」变成几倍，要用奇异值（第 5 课之后会出现）。

二阶矩阵的行列式就是一个交叉相乘再相减：

det [[a, b], [c, d]] = a·d − b·c

三种情况要分清：

det几何上发生了什么后果
2面积变 2 倍，方向不变可逆，能还原
−2面积变 2 倍，还翻了面（像照镜子）可逆，但左右手性反了
0整个平面被压成一条线或一个点不可逆，信息丢了，回不去

最后一行是重点。det = 0 意味着「有某个方向被压没了」，不同的点会被挤到同一个位置上——你没法从结果反推原来的输入，所以逆矩阵不存在。

五种常见变换，一张表记住

变换矩阵det它在干什么
旋转 θ[[cosθ, −sinθ], [sinθ, cosθ]]1整体转，面积不变

5工具表：这一课只留四条

可逆 / 逆矩阵 A⁻¹ 如果存在 B 使得 BA = AB = I（I 是单位矩阵：对角全 1、其余 0，相当于「什么都不做」），就称 A 可逆，B 记作 A⁻¹，意思是「把这次搬动原样倒回去」。 可逆 ⟺ det ≠ 0 ⟺ 没有把任何方向压扁 ⟺ 两列指向不同方向。反过来说：只要 det = 0，信息就丢了，再聪明的算法也倒不回去——这就是为什么「无解」的方程靠 det 就能看出来。
名字式子什么时候用
矩阵乘向量A·x = x₁·col₁ + x₂·col₂把一个点搬到新位置；算一层的输出
矩阵乘矩阵(AB)·x = A·(B·x)复合变换：先做 B，再做 A（注意顺序）
行列式det = ad − bc判断面积缩放几倍、是否可逆
逆矩阵A⁻¹（仅 det ≠ 0 时存在）把变换倒回去；解方程组

关于 AB 的顺序：写 AB 表示先作用 B、再作用 A，因为 (AB)x = A(Bx) 是从里往外读的。这一条几乎每个人都会错一次。

6动手：10 分钟，用 numpy 验证

打开终端，进 python3，逐行敲：

# 1. 定义矩阵 A 和向量 x
import numpy as np
A = np.array([[2, 1],
              [0, 3]])
x = np.array([1, 2])

# 2. 矩阵乘向量
print(A @ x)                # [4 6]

# 3. 换一种算法：混合两列
print(x[0]*A[:,0] + x[1]*A[:,1])  # 也是 [4 6]

# 4. 行列式 = 面积放大倍数
print(np.linalg.det(A))     # 6.0

# 5. 把单位正方形的四个角一起变换
sq = np.array([[0,0], [1,0], [1,1], [0,1]])
print(sq @ A.T)            # 每行是一个点变换后的坐标

然后做三件事（比读代码重要）：

① 把 A 改成 [[1,0],[0,1]]，看四个角有没有动。
② 把 A 改成 [[1,0],[0,0]]，看四个角被压到哪去了，det 是多少。
③ 把 A 改成 [[0,-1],[1,0]]，看正方形转了多少度，det 还是不是 1。

你应该发现：②里四个角全落在了 x 轴上，det = 0——这就是「压成一条线」。③里正方形原地转了 90°，面积一点没变，det 仍然是 1。
单位矩阵那个 ①，什么都没动——所以它叫「恒等变换」，矩阵里的 1。

7练习：三道，做完对答案

1设 A = [[1, 2], [3, 4]]，x = (1, 5)。先用「列的混合」算 A·x，再用「行乘列」验算。det 是多少？面积放大几倍？正还是负？
列混合：x 的两个数分别是两列的系数。
对答案
A·x = 1×(1, 3) + 5×(2, 4) = (1, 3) + (10, 20) = (11, 23) 验算：第一行 1×1 + 2×5 = 11；第二行 3×1 + 4×5 = 23 ✓ det = 1×4 − 2×3 = −2。面积放大 2 倍，负号说明这个变换把平面翻了面（镜像）。
2写出「逆时针旋转 90°」的矩阵，并算它作用在 (3, 1) 上的结果。
从基向量出发：(1,0) 转 90° 应该到哪？(0,1) 呢？那正好是两列。
对答案
矩阵 [[0, −1], [1, 0]] A·(3, 1) = 3×(0, 1) + 1×(−1, 0) = (0, 3) + (−1, 0) = (−1, 3) 验算：(3,1) 逆时针转 90°，应该跑到第二象限，x 变负、y 变正——(−1, 3) 对得上。
3（编程）用 numpy：A = [[1, 0.5], [0, 1]]，把单位正方形四个角变换一遍。det 是多少？正方形面积变了吗？再把 A 改成 [[1, 1], [1, 1]]，四个角落到了哪里？
用练习里的 sq @ A.T；改完 A 重新跑一次。
对答案
det = 1，面积不变——这是一个剪切变换，把正方形推成平行四边形，但没改变面积。 四个角变成 (0,0)、(1,0)、(1.5,1)、(0.5,1)，确实是个平行四边形。 改成 [[1, 1], [1, 1]] 后 det = 0，四个角变成 (0,0)、(1,1)、(2,2)、(1,1)——全部落在直线 y = x 上，正方形被压成了一条线段。 注意 (1,0) 和 (0,1) 都被送到了 (1,1)：两个不同的点挤到同一个位置，这就是「信息丢了」的样子。
