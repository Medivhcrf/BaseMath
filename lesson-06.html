主成分分析 PCA：把 12 个数压成 6 个数

第 5 课说清了「哪些方向不动」。这一课把它用在数据上，问一个完全不同的问题：一堆点里，哪个方向最值钱。

学完你能：说出 PCA 的三步（中心化 → 协方差 → 特征分解）；手算 2 维小数据的协方差矩阵和主方向；解释「特征值 = 那个方向上的方差」；用解释方差比决定压到几维；把 6 个二维点压成 6 个数并算清损失了多少；用 np.cov + np.linalg.eigh 十行实现；说清为什么必须先中心化。
这一课的路怎么走：六级台阶（每一级只解决一件事）
  1. 看清楚问题：6 个点、12 个数，其实它们几乎落在一条斜线上——两个读数在说同一件事。
  2. 把「最值钱」变成能算的数：投影之后的方差。方差大 = 点在这个方向上分得开 = 信息多。
  3. 第一步：中心化。把点挪到以均值为原点，否则你找到的是「离原点最远」，不是「分得最开」。
  4. 第二步：协方差矩阵。它是一个 2×2 的对称矩阵，把「各方向分得多开、两个坐标怎么一起动」全装进去。
  5. 第三步：特征分解。对称矩阵的特征向量就是候选方向，特征值就是那个方向的方差。
  6. 收尾：投影、重构、算损失。压到一维以后还剩多少信息？用解释方差比和重构误差两个数说话。
任何一级卡住，就退回上一级；每节开头都有一句「这一步在干什么」。

1真实问题：12 个数，其实只有 6 条信息

六个学生，记了两列数：每周自学时长，和一次小测的分数。

学生时长 x分数 y
111.2

443.8

画出来一眼就能看出：这六个点差不多躺在一条斜率为 1 的直线上。换句话说，分数几乎完全由时长决定——两列数是同一个信息的两次测量，第二列几乎没带来新东西。

那就有一个很实际的问题：既然它们是同一个信息的两次测量，我们能不能只存一个数？把 12 个数压成 6 个数，代价是什么？

能不能压，关键看「点在哪个方向上分得最开」。如果所有点都挤在一条线上，那沿着这条线记一个坐标就够了；垂直于它的那个坐标全是噪声，扔掉不心疼。

PCA 的全部思想就一句：找一个方向，把所有点投影过去，让投影后的方差最大。
方差大 = 投影后的点分得最开 = 丢掉的信息最少。

注意这句话里没有「矩阵」「特征值」——它们是解题工具，不是问题本身。先把问题看清楚，工具才有意义。

你会看到一件事：残差不是「越小越好」那么简单，它在 44.4° 附近有一个光滑的最低点（像个碗），左右两边都上升。这个最低点不是试出来的，它可以用特征分解一次算出来——下面三节就干这件事。

3三步：中心化 → 协方差 → 特征分解

第一步：中心化（先看清楚「围绕什么」分得开）

为什么不能直接用原始坐标？因为我们要的是「点彼此之间分得多开」，而原始坐标里混着「离原点有多远」。先把所有点平移，让均值落在原点：

均值 μ = (3.5, 3.5167)　　中心化后：aᵢ = pᵢ − μ
中心化每个点减去整列的平均值，让数据以均值为中心：X ← X − mean(X)，axis=0 表示按列减。 这一步只做平移，不改变任何点之间的距离和相对位置，但它决定了后面「原点在哪」。不中心化会怎样：§6 有一个具体的反例，主方向会跑到 45° 上去，而那是「均值的方向」，不是「分得最开的方向」。

中心化之后，六个数对（保留三位小数）：

2−1.5−1.6167
3−0.5−0.4167

第二步：协方差矩阵（把「分得多开」装进一个矩阵）

「分得多开」用方差量，但这里有两列，所以还要记「它们怎么一起动」。这两件事正好填满一个 2×2 矩阵：

协方差矩阵中心化之后 C = XᵀX / n。对角线上是两列各自的方差，非对角线上是两列的协方差（一起变大还是反向走）。 为什么是 XᵀX / n：这正是第 4 课的正规方程里那个 XᵀX——XᵀX 的第 i 行第 j 列 = 第 i 列与第 j 列的内积。所以「协方差 = 两列的内积 ÷ n」，就是内积（第 1 课）在数据上的名字。 分母用 n 还是 n−1：理论推导用 n，无偏估计用 n−1。几万个样本时没区别，六个点时有 20% 的区别。本课统一用 n，代码里 np.cov 默认用 n−1，注意这个差。特征向量完全不受影响，只有特征值的绝对大小差一点。

那五个数在哪？照第 4 课的老规矩，逐个内积算：

C 的某个位置怎么算值
C₁₁（x 的方差）(−2.5)² + (−1.5)² + … + 2.5² 再 ÷ 62.9167
C₂₂（y 的方差）(−2.3167)² + … + 2.3833² 再 ÷ 62.7914
C₁₂ = C₂₁（协方差）(−2.5)(−2.3167) + … 再 ÷ 62.8417
C = [[2.9167, 2.8417], [2.8417, 2.7914]]

读一下这个矩阵：两个方差差不多大（2.92 与 2.79），说明两列各自都挺分散；协方差 2.84 几乎是方差本身——说明两列几乎完全同步变化。这正是「它们是一条斜线」的代数说法。

第三步：特征分解（方向 = 特征向量，信息量 = 特征值）

协方差矩阵是对称的（C₁₂ = C₂₁），所以第 5 课结论全套可用：两个实特征值、特征向量互相垂直、可以用 eigh。直接算：

tr = 2.9167 + 2.7914 = 5.7081　　　det = 2.9167×2.7914 − 2.8417² = 0.0648
λ = (5.7081 ± √(5.7081² − 4×0.0648)) / 2 = (5.7081 ± 5.6847) / 2
λ₁ = 5.6964　　λ₂ = 0.0117

两个特征值差了一个量级不止：5.70 对 0.01，相差约 487 倍。这说明一件事——数据几乎完全落在一个方向上。

对应的方向（已归一化）：v₁ = (0.7149, 0.6993)，也就是约 44.4° 的那条线；v₂ = (−0.6993, 0.7149)，和它垂直。和 §2 里拖出来的最优角度一致。

主成分协方差矩阵的特征向量。按特征值从大到小排：第一主成分 PC1 是方差最大的方向，第二主成分 PC2 是与 PC1 垂直的方向里方差最大的那个。 「垂直」不是巧合：对称矩阵的不同特征值对应的特征向量一定正交（第 5 课）。所以主成分是一组互相垂直的新坐标轴——这就是「换一套坐标系看数据」。 特征向量的方向有两个朝向（v 和 −v 都行）。所以 PCA 算出来的 (0.71, 0.70) 和 (−0.71, −0.70) 是同一个方向；不同软件连符号都可能不一样，别把它当 bug。

4为什么特征值就是方差：一次推导，两个结论

这一节回答「凭什么说特征向量就是最值钱的方向」。骨架只有三行。

设方向是单位向量 u（长度 1，只关心朝向）。把每个中心化后的点 aᵢ 投到 u 上，投影坐标是 uᵀaᵢ（第 1 课的内积）。投影后的方差是：

方差(u) = (1/n) Σ (uᵀaᵢ)² = uᵀ [(1/n) Σ aᵢaᵢᵀ] u = uᵀ C u

所以我们要解的问题是「在 ‖u‖ = 1 的约束下让 uᵀCu 最大」。用第 4 课那套「求极值 → 让导数等于 0」的办法（拉格朗日乘子），会得到：

C u = λ u　　（λ 是乘子，也就是特征值）

这一行把整件事说完了：最优方向满足「协方差矩阵作用上去只改变长度」——它正是 C 的特征向量。而且把 u 代回目标函数：

uᵀCu = uᵀ(λu) = λ(uᵀu) = λ
两个结论，一次得到：① 让方差最大的方向 = C 的特征向量；② 在那个方向上，方差恰好等于特征值。
所以「λ 大」不是数值大，是「这个方向上数据铺得开」。

拿我们的数据验一遍。第一主成分方向上的投影坐标是：

学生123456
投影坐标−3.4071−2.2028−0.64880.55562.24943.4537

这六个数平方和 ÷ 6 = 5.6964，正好等于 λ₁。这不是巧合，是上面那个等式。

解释方差比某个主成分的方差占总方差的比例：λᵢ / Σλⱼ。也就是「这一维吃掉了多少信息」。 总方差 = 所有特征值之和 = tr(C)（第 5 课的迹）。我们的数据：5.6964 + 0.0117 = 5.7081 = 2.9167 + 2.7914 ✓。 别把它读成「准确率」：99.8% 说的是「这两列数里 99.8% 的波动，能被一个方向解释」，不是「预测对了 99.8%」。

所以：PC1 吃掉 5.6964 / 5.7081 = 99.8%，PC2 只剩 0.2%。压到一维，基本上什么都没丢。

5压到一维：投影、重构、算清损失

「降维」在操作上就是两行：

降维：t = X · v₁　（每个点变成一个数）　　重构：X̂ = t · v₁ᵀ + μ　（再从数变回点）

我们的数据压缩后是六个坐标（上面那张表），再按下面的公式还原：

学生原来 (x, y)压成 1 个数还原回 (x̂, ŷ)差了多少
1(1, 1.2)−3.4071(1.0644, 1.1342)几乎没差
2(2, 1.9)−2.2028(1.9253, 1.9763)几乎没差
3(3, 3.1)−0.6488(3.0362, 3.0630)几乎没差
4(4, 3.8)0.5556(3.8971, 3.9051)几乎没差
5(5, 5.2)2.2494(5.1080, 5.0896)几乎没差
6(6, 5.9)3.4537(5.9690, 5.9317)几乎没差

损失用重构误差量（就是每个点被丢掉那一段的长度平方之和）：

SSE = 0.0700　　总方差 = 34.2483　　残差占比 = 0.204%

注意这两个数不是一回事：99.8% 是「每个方向上的方差比」，0.204% 是「按样本点算的总平方误差占比」。它们互为补数（0.204% ≈ 1 − 99.8%），因为用 PC1 重构丢掉的正是在 PC2 上的分量。

重构误差压到 k 维再还原，与原始数据的差：‖X − X̂‖²。它等于被丢掉的那些主成分的方差之和（乘 n）。 实用意义：它告诉你「降维到底损失了多少」。如果残差占比 0.2%，那用一维代替二维是划算的；如果残差占 40%，那压下去就伤筋动骨了。

再回看 §2 那张图：把角度从 0° 拖到 45°，残差平方和从 16.75 掉到 0.07（0° → 16.7483、30° → 2.1705、40° → 0.2679、45° → 0.0742、90° → 17.5）。这个「碗」的最低点在 44.4°，不是 45——因为数据并不完全在 45° 上，而是 44.4°。差这 0.6°，就是 PC1 和「斜率 1」的区别。

6反例：不中心化会找到什么

同样的数据，如果跳过中心化、直接对原始点求「离原点最能解释的方向」，也就是用没减均值的 S = PᵀP / n：

S = [[15.1667, 15.1500], [15.1500, 15.1583]]　⟹　λ = 30.3125 和 0.0125

第一主成分的方向是 (0.7072, 0.7070)，也就是整整 45°——正好指向「均值点 (3.5, 3.52) 的方向」。解释方差比 99.96%，比中心化之后的 99.8% 还「好看」。

但它错了，错在两个地方：

绕均值（正确）绕原点（错误）
PC1 方向44.4°，贴着数据的走向45.0°，指向「数据离原点有多远」
它回答的问题点彼此之间怎么散开点离原点有多远
换个坐标原点会怎样不变（平移不改变相对位置）全变，结果没有意义

这个反例还顺带解释了为什么「解释方差比越高越好」是错的读法：99.96% 那个数字更漂亮，却是假象——因为均值把原点推远了，30.31 里绝大部分是「均值的长度」，不是「数据的散布」。

一句话：PCA 找的是「围绕均值的散布」，不是「离原点多远」。
所以 X − X.mean(axis=0) 这一步永远不能省。

7五个坑：真正用的时候会踩到

坑为什么怎么办
量纲不同「时长（小时）」和「分数（分）」的数值尺度差几十倍，方差大的那列自动当第一主成分，跟重要性无关先标准化：(X − μ) / σ，每列方差归一。这时的 PCA 等价于对相关矩阵做特征分解
特征值接近两个方向方差差不多时，把 PC1/PC2 固定下来是不稳的：数据抖一点，方向就大幅旋转别硬解读单个方向，改成看子空间（前两个一起看）
数据非线性PCA 只能找直线方向。数据要是弯的（S 形、圆环），它会给出误导的答案换核 PCA、t-SNE、UMAP——本课不管它们
把解释方差当预测力「前两维解释了 95% 的波动」不等于「能预测 95% 的目标」预测力要单独做交叉验证，跟方差是两回事
样本太少n 个样本最多只有 n−1 个非零主成分；六个点算出来的 2×2 协方差本身就很吵样本数至少是维度的很多倍，否则保留的主成分数要更保守

还有一个更隐蔽的：先做 PCA 再用结论做别的统计，会让置信区间变乐观（因为方向是从同一批数据里挑的）。严格做法是把选方向放在训练集里做，再套到测试集上。

8工具表：numpy 里十行就够

要什么写法说明
中心化X - X.mean(axis=0)axis=0 是按列（每个特征各自减自己的均值）
协方差矩阵np.cov(Xc, rowvar=False)默认除以 n−1；rowvar=False 表示「一列是一个变量」
特征分解w, V = np.linalg.eigh(C)协方差是对称矩阵，必须用 eigh：升序、实数、向量正交
取主成分V[:, ::-1][:, :k]eigh 是升序，先反过来取前 k 列
降维 / 重构T = Xc @ Vk / Xc @ Vk @ Vk.T两条都是矩阵乘法，没有循环
SVD 等价做法U, s, Vt = np.linalg.svd(Xc)更稳定，s²/n 就是特征值；数据大时用这个
累计解释方差从最大往下累加 λᵢ / Σλ，用来决定「压到几维」。常见做法：累计超过 90% 或 95% 就停。 例：两个特征值时累计是 99.8% 和 100%。如果数据有 50 维，通常前 5–10 维就能到 95%——这就是 PCA 在图像、文本、基因数据里天天被用的原因。 90% 是个经验阈值，不是定理。要压缩存储可以激进一点，要保留可解释性就保守一点；报出来的是「我选了 k 维，累计解释了 x% 方差」。

9能跑的代码：完整一遍

# 六个点，两列：时长、分数
import numpy as np
X = np.array([[1., 1.2], [2., 1.9], [3., 3.1],
              [4., 3.8], [5., 5.2], [6., 5.9]])

# 1) 中心化（不能省）
mu = X.mean(axis=0)            # [3.5    3.5167]
Xc = X - mu

# 2) 协方差矩阵（这里故意用 n，和正文一致）
C = Xc.T @ Xc / len(X)
print(C)                        # [[2.9167 2.8417] [2.8417 2.7914]]

# 3) 特征分解（对称矩阵必须用 eigh）
w, V = np.linalg.eigh(C)
w = w[::-1]; V = V[:, ::-1]    # 变成从大到小
print(w)                        # [5.6964 0.0117]
print(w / w.sum())              # [0.998 0.002] 解释方差比
print(V[:, 0])                 # 第一主成分方向 (0.715, 0.699)
print(np.degrees(np.arctan2(V[0, 1], V[0, 0])))   # 44.4 度

# 4) 降维到 1 维，再重构，算损失
t = Xc @ V[:, 0]                # 六个投影坐标
rec = np.outer(t, V[:, 0]) + mu
sse = ((X - rec) ** 2).sum()
print(t.round(4))               # [-3.4071 -2.2028 -0.6488  0.5556  2.2494  3.4537]
print(rec.round(4))
print(sse, sse / ((Xc) ** 2).sum())   # 0.0700, 0.00204 -> 只剩 0.204%

# 5) 顺手验证：投影坐标的方差 = λ1
print(t.var())                   # 5.6964，正好是第一个特征值

最后一行的 t.var() 是 §4 那个结论的实测：投影后的方差 = 特征值。可以把它当成「PCA 算对了没有」的一键检查。

10练习：六道，做完对答案

题型：① 手算 ② 手算 ③ 判断 ④ 应用 ⑤ 找错 ⑥ 写代码。②④ 要动手算，③⑤ 是概念陷阱。

1. 三个点 (1, 1)、(2, 3)、(3, 2)。求均值、中心化后的矩阵、协方差矩阵。
看答案

均值 = (2, 2)。中心化后：(−1, −1)、(0, 1)、(1, 0)。

协方差 C = XᵀX/3，逐个内积：C₁₁ = (1+0+1)/3 = 2/3 ≈ 0.6667；C₂₂ = (1+1+0)/3 = 2/3 ≈ 0.6667；C₁₂ = (1·1 + 0·1 + 1·0)/3 = 1/3 ≈ 0.3333。

C = [[0.6667, 0.3333], [0.3333, 0.6667]]。

2. 接上题：求特征值和特征向量，并说出解释方差比。
看答案

tr = 4/3、det = (2/3)² − (1/3)² = 4/9 − 1/9 = 3/9 = 1/3。所以 λ² − (4/3)λ + 1/3 = 0 → 3λ² − 4λ + 1 = 0 → λ = 1 和 λ = 1/3。

λ = 1 的方向：解 (C − I)v = 0，得到 x = y，所以 v₁ = (1, 1)/√2（45°）。λ = 1/3 的方向 (1, −1)/√2。

解释方差比：1/(1 + 1/3) = 75% 和 25%。压到一维会丢掉 25% 的波动——比正文那组数据差很多，因为这三点根本没排成一条线。

3. 判断题：如果数据全部落在一条直线上（比如 (1,2)、(2,4)、(3,6)），第二主成分的特征值是多少？为什么？
看答案

恰好是 0。因为这三点中心化后是 (−1,−1)、(0,0)、(1,1)，全都沿 (1,1) 方向，垂直于它的方向上一个点也没有——投影过去全是 0，方差自然是 0。

算一下：C = [[2/3, 4/3], [4/3, 8/3]]，tr = 10/3、det = 0，所以 λ = 10/3 和 0 ✓。这也说明「特征值为 0 ⟺ 那个方向没有数据」，和第 5 课「特征值为 0 ⟺ 方向被压成零」是同一件事。

4. 接练习 1、2：把三个点压到 PC1 上，写出三个投影坐标；再把它们还原，算重构误差。
看答案

投影坐标 t = Xc · v₁，v₁ = (0.7071, 0.7071)：(−1,−1)→−1.4142；(0,1)→0.7071；(1,0)→0.7071。

还原：t·v₁ᵀ + μ → (1,1)、(2.5,2.5)、(2.5,2.5)。原始点是 (1,1)、(2,3)、(3,2)。

重构误差平方和 = 0 + (0.5² + 0.5²) + (0.5² + 0.5²) = 1.0。总方差（平方和）= 2 + 1 + 1 = 4，所以残差占 25%，和「解释方差 75%」对得上 ✓。

5. 有人说：「我的 PCA 第一主成分解释了 99.9% 的方差，所以这个方向一定很有意义。」哪里可能出问题？至少说出两种检查。
看答案

可能的问题：① 没中心化——那样 PC1 会指向均值方向，比例虚高（正文 §6 的 99.96% 就是假象）；② 量纲没统一——某一列的数值尺度远大于其它列，它自动当主成分；③ 数据本身接近一维（共线、几乎重复的列），那 99.9% 是在说「你重复采集了同一个东西」。

两种检查：先看中心化前后结果差多少；再画一下前几个主成分的散点图，看它是不是只反映某一列的尺度。

6. 写代码：对正文那六个点做 PCA，打印两个主成分方向、解释方差比、以及压到一维的残差占比，并验证「投影坐标的方差 = 第一个特征值」。
看答案 
import numpy as np
X = np.array([[1.,1.2],[2.,1.9],[3.,3.1],
              [4.,3.8],[5.,5.2],[6.,5.9]])
Xc = X - X.mean(axis=0)
C = Xc.T @ Xc / len(X)
w, V = np.linalg.eigh(C)
w, V = w[::-1], V[:, ::-1]
print(V[:, 0])                 # [0.7149 0.6993]
print(w / w.sum())              # [0.998 0.002]
t = Xc @ V[:, 0]
rec = np.outer(t, V[:, 0]) + X.mean(axis=0)
print(((X - rec)**2).sum() / (Xc**2).sum())   # 0.00204
print(np.isclose(t.var(), w[0]))       # True
明天的问题：到这里「空间」这一段就收尾了——向量、内积、矩阵、行列式、秩、特征值、PCA，一条线串完了。下一步是「变化」：输入动一点，输出动多少。导数是这件事的答案，而 PCA 里那个「找让某个量最大的方向」的做法，会原封不动地变成梯度上升。第 7 课从斜率开始。

11收尾：四个问题，答上来就算学会

① PCA 到底在优化什么？
看答案在找一个单位方向，让数据投影上去以后方差最大（等价地：让被丢掉的残差平方和最小）。两个说法是同一件事的两面。
② 为什么协方差矩阵的特征向量就是答案？
看答案因为投影后的方差可以写成 uᵀCu。让它最大得到的条件恰好是 Cu = λu——也就是「u 是 C 的特征向量、λ 是那个方向上的方差」。这是第 4 课「求极值让导数为 0」的同一套路，只是变量变成了一整个方向。
③ 为什么必须先中心化？
看答案不中心化时，原点被人为地放在别处，你最大化的是「离原点有多远」，而不是「点彼此分得多开」；平移数据结果就会变，说明这个答案不描述数据结构。正文 §6 的 99.96% 就是这种假象。
④ 解释方差 99% 能说明模型好吗？
看答案不能。它只说「数据的大部分波动能用少数几个方向表示」，不说这些方向与你关心的目标有关，也不说预测准确率。模型好不好要另做验证。
